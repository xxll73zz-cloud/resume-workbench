# 简历实时定制工作台

一个在本机运行的简历工作台：整理基础经历，结合目标岗位和公司资料分析能力证据，编辑简历并导出 PDF 或 PNG。

## 功能

- 基础简历、目标岗位与公司资料录入及本机保存
- 多段教育、实习和项目经历识别与排序
- 能力证据与岗位要求对照
- 简历预览、板块编辑、多版本保存与调用
- PDF 打印与 PNG 导出
- 可选连接 OpenAI 格式兼容接口进行 AI 改写；不配置 API 密钥也可使用录入、预览和导出功能

## 本机运行

需要 Node.js 18 或更新版本。此项目没有第三方运行依赖。

    git clone https://github.com/xxll73zz-cloud/resume-workbench.git
    cd resume-workbench
    npm start

在浏览器打开 http://127.0.0.1:8787/ 。

若希望使用 AI 改写，在启动前设置所选服务的环境变量：

    $env:AI_API_KEY = "你的密钥"
    $env:AI_BASE_URL = "服务商提供的 OpenAI 兼容地址"
    $env:AI_MODEL = "服务商提供的模型名"
    npm start

未设置 AI_BASE_URL 时默认使用 OpenAI API 地址。密钥只应保存在本机环境变量，勿提交到 GitHub。

## 在线使用

公开网页：https://xxll73zz-cloud.github.io/resume-workbench/

在线版可录入资料、查看岗位能力分析、编辑与导出简历，也可复制资料给自己的 AI 服务并把生成结果粘贴回网页。在线版不连接项目作者的模型账号。
如需使用网页中的自动 AI 改写按钮，请按“本机运行”步骤启动服务，并配置自己的 AI_API_KEY、AI_BASE_URL 和 AI_MODEL。

## 数据与隐私

网页资料保存在当前浏览器的本地存储中，不会随仓库代码上传。不同浏览器或设备不会自动同步，请使用页面中的备份功能保存自己的资料。只有在主动调用 AI 改写时，网页才会把填写的资料发送到你配置的模型服务。发布仓库时请勿加入个人简历、照片、导出文件、浏览器存储或 API 密钥。

## 使用提醒

岗位能力分析需要人工核对经历证据。没有可核实依据的量化结果不能直接写入投递版简历。
